# Blinkit Grocery Data Analysis (Power BI)

## Project Overview
An interactive Power BI dashboard analyzing Blinkit's grocery sales, performance metrics, and consumer insights to drive data-backed business decisions.

## Key Insights & Features
* **Sales Performance:** Visualized total revenue, average order value, and top-performing product categories.
* **Customer Metrics:** Analyzed consumer rating trends and purchase patterns across different item types.
* **Outlet Performance:** Segmented sales data by outlet size, location type, and establishment year to identify growth opportunities.
* **Advanced DAX & Power Query:** Leveraged custom Data Analysis Expressions (DAX) measures and data cleaning workflows for accurate reporting.

## Tech Stack
* **Business Intelligence:** Power BI Desktop
* **Data Transformation:** Power Query
* **Analytical Formulas:** DAX (Data Analysis Expressions)
