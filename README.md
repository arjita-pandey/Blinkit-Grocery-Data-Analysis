# 🛒 Blinkit Grocery Data Analysis Dashboard

![Power BI](https://img.shields.io/badge/Power_BI-F2C811?style=for-the-badge&logo=microsoft-power-bi&logoColor=black)
![Power Query](https://img.shields.io/badge/Power_Query-0078D4?style=for-the-badge&logo=microsoft&logoColor=white)

An interactive, enterprise-grade Power BI business intelligence dashboard designed to ingest, transform, and analyze multi-layered retail metrics. This pipeline evaluates grocery sales revenue, customer ratings, and outlet logistics to extract actionable data-backed operational insights.

---

## 📌 Analytical Key Insights & Core Features

### 📈 1. Sales Performance & Matrix Evaluations
* **Revenue Tracking:** Visualizes multi-channel total revenue, average order values (AOV), and overall pricing trends.
* **Product Trends:** Identifies top-performing grocery categories and high-velocity item groupings.

### 👥 2. Customer Sentiment & Behavioral Patterns
* **Rating Correlation:** Tracks consumer satisfaction rating trends across divergent item types to optimize inventory tiering.
* **Volume Analysis:** Maps purchase density and consumption patterns across product variations.

### 🏬 3. Operational Outlet Logistics
* **Tier Breakdown:** Segments critical performance indicators (KPIs) by outlet size, urban location classification, and establishment timelines to isolate development anomalies.
* **Growth Identification:** Isolates underperforming segments and uncovers localized market opportunities.

---

## 🏗️ Technical Architecture & Workflow Data-Flow

| Analysis Layer | Technical Component | Core Engineering Functions |
| :--- | :--- | :--- |
| 🗃️ **Data Transformation** | Power Query Engine | Executes data cleaning workflows, structural parsing, and cast type normalization. |
| 🧠 **Analytical Modeling** | Custom DAX Measures | Leverages advanced Data Analysis Expressions (DAX) for precise time-intelligence reporting and cross-filtering aggregations. |
| 📊 **Business Intelligence** | Power BI Desktop | Centralized engine for semantic layer deployment, data modeling, and performance scoring. |
